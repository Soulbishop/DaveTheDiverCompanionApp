# Dave the Diver Fish Database

This package contains:

## Files:
- dave_diver_fish_complete.csv: Complete fish database in CSV format
- dave_diver_fish_complete.json: Complete fish database in JSON format
- images/: Directory containing all fish images

## Data Fields:
- name: Fish name
- zone: Location zone
- difficulty: Catch difficulty (1-99)
- active_time: When fish is active (Day/Night/Both)
- weight: Fish weight
- meat_stars: Star rating (1-9)
- drops: Ingredients obtained from fish
- recipes: Recipes that use this fish
- image_url: Original image URL
- image_filename: Local image filename
- wiki_url: Link to wiki page
- caught: Tracking field for companion app
- breeding_pair: Tracking field for breeding pairs
- is_dlc: Whether fish is from DLC content
- is_event_locked: Whether fish is locked behind events
- best_capture_method: Recommended capture method

## Usage:
Import the CSV or JSON file into your companion app.
Use the image files for displaying fish icons.
